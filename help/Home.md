# Telar Notes help

This folder is a regular vault. Everything here is plain Markdown, so you can read it, link it and edit it like any other note. Switch back to your own vault from **Settings > Vaults**.

- [[Editing]]: live preview, formatting, embeds, tables, diagrams
- [[Links and search]]: wikilinks, backlinks, tags, graph, search
- [[Tasks]]: checkboxes, statuses, dates, task queries
- [[Task references]]: show one task from another note
- [[Daily notes]]: today's note and the calendar
- [[Drawings]]: Excalidraw files
- [[Vaults and settings]]
- [[MCP and AI clients]]: connect AI assistants via `/mcp`
- [[Shortcuts]]
