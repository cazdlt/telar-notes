# Vaults and settings

A vault is a folder of Markdown files. Add as many as you like under **Settings > Vaults** (folder picker or absolute path), mark one as default and switch between them. Removing a vault from the list never touches its files.

Deleting a file moves it to the vault's hidden `.trash/` folder, so it can be recovered.

Settings cover theme (dark or light), aesthetic, font size, persistent live preview, the attachment folder and the Tasks, Periodic Notes, Recent Files, Folder Notes and Excalidraw options. Vault-specific options are stored per vault.

**Open docs** in settings opens this help vault.
