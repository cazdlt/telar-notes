# Daily notes

The sun icon in the left sidebar opens today's note, creating it when it does not exist yet. Folder, date format and template come from **Settings > Plugins > Periodic Notes** (default `diario/YYYY/MM/YYYY-MM-DD.md`).

The calendar in the right panel marks days that have a note. Click a day to open it.

**Import Obsidian** in settings copies these options from an existing vault.
