# Links and search

## Links

- `[[Note]]` links to a note by name. Use `[[folder/Note]]` when two notes share a name, `[[Note#Heading]]` for a section and `[[Note|text]]` for custom text.
- Standard `[text](url)` links work too.
- Click a link to open it. Option-click edits it instead.

## Backlinks, tags and properties

The right panel shows the current note's backlinks, outgoing links, tags and frontmatter properties. Embeds (`![[...]]`) are not counted as links.

## Graph

Open the graph from the left sidebar to see notes and the links between them.

## Search

Press `⌘K` for search. Modes: all, title, content, tags and links. `⌘P` opens title search and `⌘F` on an open note finds inside it.
