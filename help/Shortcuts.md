# Shortcuts

| Shortcut | Action |
|---|---|
| `⌘K` | Search |
| `⌘P` | Search titles |
| `⌘F` | Find in note |
| `⌘N` | New note |
| `⌘S` | Save now |
| `⌘G` | Graph view |
| `⌘[` / `⌘]` | Back / forward |
| `Option` + click | Edit the source of a rendered element |
| `[[^^` | Insert a task reference |
